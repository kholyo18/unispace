# UniSpace campus identity

Approved direction: friendly university facade, dark green with an emerald doorway and an ivory background. Source asset: university-mark.png. Generated with the built-in image generation tool from the user-approved concept; preserve this artwork rather than redesigning it in code.

Preparation prompt: retain the approved university and rounded trees; remove the presentation wordmark; output a square ivory app-icon asset with clean dark-green architectural details and no additional text.

The native launcher assets are generated by: powershell -File scripts/generate_launcher_icons.ps1.
The shared Flutter mark is UniSpaceBrandMark. Intro motion runs once while startup work proceeds and never imposes a minimum delay. Respect reduced motion. Login, security and release-policy decisions remain independent of the presentation.

Android adaptive icons use a native 18% inset wrapper to preserve the full university artwork inside launcher masks. Keep the wrapper when regenerating assets; launcher-icons 0.13.1 does not support the YAML inset option.
