هذه القواعد تكمل شروط الاستخدام وتحدد السلوك المتوقع داخل مساحات المجتمع في UniSpace.

1. الهدف والنطاق

تهدف قواعد مجتمع UniSpace إلى إبقاء المنشورات والتعليقات والرسائل والمجموعات وغيرها من مساحات التفاعل مفيدة وآمنة للطلبة. تسري هذه القواعد على المحتوى والسلوك داخل الوظائف الاجتماعية المتاحة فعليًا.

هذه القواعد تكمل شروط الاستخدام ولا تستبدلها، ولا تمنح UniSpace صفة جامعة أو جهة رسمية. الخلاف أو النقد المهذب لا يعد مخالفة لمجرد أنه مزعج أو غير متفق عليه.

2. الاحترام ومنع المضايقة

يُحظر التهديد أو التنمر أو التحرش أو الإهانة المتكررة أو استهداف شخص بقصد إذلاله أو إخافته أو دفع الآخرين لمهاجمته. ويُحظر نشر خطاب كراهية أو تمييز ضد أشخاص أو مجموعات على أساس صفات محمية بالقانون.

يمكن مناقشة الأفكار والمواد الدراسية والقرارات الجامعية بحدة أو نقد، لكن دون تحويل النقاش إلى إساءة شخصية أو حملة مضايقة.

3. السلامة والمحتوى شديد الحساسية

يُحظر المحتوى الذي يستغل القاصرين أو يعرّضهم للخطر، والمحتوى الجنسي الصريح، والتهديدات الجدية، وتمجيد العنف أو تشجيع إيذاء النفس أو الأنشطة الخطرة. كما يُحظر نشر محتوى صادم بقصد الإيذاء أو التخويف.

المحتوى التعليمي أو التوعوي الحساس يُقيّم بحسب سياقه وضرورته وطريقة عرضه، ولا تمنح الصفة التعليمية استثناءً تلقائيًا من قواعد السلامة.

4. الأنشطة غير القانونية والاحتيال

يُحظر استخدام UniSpace لتسهيل نشاط غير قانوني أو احتيال أو ابتزاز أو انتحال معاملات أو مستندات، أو طلب بيانات سرية من المستخدمين بطرق مضللة.

لا يُسمح بعروض أو روابط تهدف إلى خداع الطلبة أو الاستيلاء على حساباتهم أو أموالهم أو معلوماتهم الشخصية.

5. الخصوصية والبيانات الشخصية

لا تنشر عنوان شخص أو رقم هاتفه أو وثائقه أو صوره الخاصة أو بياناته الحساسة دون حق أو إذن مناسب. ولا تستخدم معلومات حصلت عليها من محادثة خاصة لإحراج الطرف الآخر أو تعريضه للخطر.

عند الإبلاغ عن مخالفة، شارك أقل قدر من البيانات اللازمة لفهم البلاغ وتجنّب نشرها علنًا.

6. انتحال الهوية والمعلومات المضللة

يُحظر انتحال طالب أو أستاذ أو جامعة أو إدارة أو جهة أخرى، أو إنشاء حساب يوهم المستخدمين بعلاقة رسمية غير موجودة. كما يُحظر تزوير الشارات أو المستندات أو الادعاءات الأساسية التي تهدف إلى خداع الآخرين.

يمكن مشاركة الرأي أو المعلومة غير المؤكدة إذا عُرضت بوضوح على هذا الأساس، أما الادعاءات المضللة المتعمدة التي قد تسبب ضررًا فيمكن تقييدها أو إزالتها.

7. حقوق النشر والنزاهة الأكاديمية

لا ترفع كتابًا أو درسًا أو امتحانًا أو ملفًا لا تملك حق مشاركته، ولا تنسب عمل شخص آخر لنفسك. يُسمح بالنقاش والتلخيص والمساعدة الدراسية المشروعة مع احترام حقوق أصحاب المواد وقواعد المؤسسة التعليمية.

يُحظر استخدام المنصة لتزوير أعمال أكاديمية أو بيع نتائج أو مستندات مزيفة أو تسهيل الغش المنظم.

8. الرسائل والتواصل غير المرغوب

احترم رغبة الطرف الآخر في إيقاف التواصل. يُحظر إرسال رسائل متكررة غير مرغوبة، أو ملاحقة مستخدم عبر حسابات متعددة بعد أن يطلب التوقف، أو استخدام الإشارات والمجموعات لإزعاج أشخاص بعينهم.

التواصل الفردي لا يمنح حقًا في نشر المحادثة الخاصة خارج غرضها دون أساس مشروع.

9. السبام والإعلانات والاستغلال التجاري

يُحظر السبام والروابط المضللة والحسابات الآلية المزعجة والترويج المتكرر خارج السياق. يجب تمييز المحتوى التجاري أو الممول بوضوح عند السماح به.

لا يجوز شراء التفاعل أو استغلال نظام النقاط أو المكافآت أو أي ميزة مستقبلية لتشجيع محتوى مخالف أو سلوك مزعج.

يمكن أن تشمل إجراءات الإشراف إخفاء محتوى أو حذفه أو تقييد وظيفة أو تعليق حساب بحسب نوع المخالفة وخطورتها وتكرارها. لا يعني عدد البلاغات وحده أن المستخدم مذنب، ويُراجع السياق المتاح قبل الإجراء قدر الإمكان.
