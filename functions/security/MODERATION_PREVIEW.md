# Report-bound moderator preview

readModerationPreview verifies bearer/revocation and the same server moderator roster; transaction checks cutoff/account and resolves the target from a stored report. Hidden/private target content is intentionally available for moderator inspection. Post projection omits voter arrays and unrelated comments; comment reports include only the uniquely matching nested comment plus post context. Account cards retain their report details, with no unrelated post lookup. No deleted-comment historical fallback in live preview. Historical snapshots remain in report details.

Client uses report IDs, stable card keys, account-change clearing and generation checks. Missing/error preview clears content; opening the ordinary discussion uses ordinary authorized-post access, so hidden/private content stays reviewable only in moderator preview. Deploy callable first. Rules still need reconciliation to deny direct unauthorized reads. No deployment/runtime tests. Deferred: nonmoderator/revoked access, private/hidden/deleted content, comment ambiguity, account switches, recycled cards, timestamps, media and discussion access. Preview is a snapshot and does not instantly revoke already-rendered media when remote permissions change.
