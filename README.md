# UniSpace — Android ARM64

Download `UniSpace-Android-ARM64.zip`, extract it, and install `UniSpace.apk` on an ARM64 phone running Android 7 or newer.

Debug build: version 1.0.0 (2), application ID `dz.fachub.fachub`, target SDK 36. APK signature verified with apksigner (v2). Physical phone installation has not been tested.

Source commit: 1d8b6fc26d2b1e16bad3dcdbd1673b5739646dc0

Build dependencies include uCrop 2.2.11 compiled from unchanged official source and a Flutter ARM64 engine artifact supplied by the project owner.
